# Рейтинг груп

Сторінка: `https://phys-kpkb.github.io/gamma/`, а посилання на конкретну групу виглядає так: `…/gamma/#101`.

- **Учні** просто відкривають посилання. Вони бачать бали, а натиснувши на студента, ще й історію його балів і скільки разів його викликали. Змінювати там нічого не можна.
- **Викладач** натискає замок унизу і один раз на кожному своєму пристрої вводить GitHub-токен. Далі кожна зміна сама зберігається комітом у `data.json`.

## Токен для викладача

1. https://github.com/settings/personal-access-tokens/new (Fine-grained token)
2. Repository access → Only select repositories → `gamma`
3. Permissions → Repository → Contents: **Read and write**
4. Вставте токен у вікно, яке відкривається замком на сторінці.

Токен зберігається тільки в браузері того пристрою, де його ввели. Вийти можна через замок → «Вийти на цьому пристрої».

## Як це влаштовано

- Усі бали лежать у `data.json`, де кожен студент записаний окремим рядком. Тому в історії комітів видно, хто, коли й скільки отримав.
- Учні бачать зміни приблизно за 1–2 хвилини: сторінка сама перевіряє оновлення кожні 30 секунд.
- Якщо бали ставили з двох пристроїв одночасно, зміни зливаються по групах.
